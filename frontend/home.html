HOW PHISHGUARD DETECTS

Two layers of phishing detection.

🤖

Machine Learning

A Random Forest machine learning model analyzes 18 URL characteristics and predicts whether the URL is likely phishing or legitimate.

🛡️

Rule-Based Security Layer

Additional security rules inspect suspicious keywords, HTTPS usage, IP addresses, hyphens, subdomains, obfuscation and other URL patterns.

🔎

Explainable Detection

Instead of showing only a prediction, PhishGuard explains the suspicious indicators that contributed to the overall phishing risk.

HOW IT WORKS

Three simple steps.

03

WHY A MULTI-LAYER APPROACH?

AI prediction + security rules.

🧠

AI-Based Prediction

Machine learning identifies patterns learned from phishing and legitimate URL examples.

⚙️

Security Rules

Explicit security rules detect known suspicious URL characteristics independently of the ML prediction.

📊

Overall Risk

The system combines the available ML probability and security indicators to produce LOW, MEDIUM or HIGH risk.
